# Everything the desktop session is, and nothing an application needs at build
# time: KWin, the Plasma shell and its daemons, SDDM, the portals, the input
# method, KDOS's own Plasma code and daemons, and the meta ports. The Plasma
# libraries that Gear applications link (libplasma, kpipewire,
# plasma-activities, union and the rest) are 43_toolkits. A port listed here is
# never named in the `depends` of a 41-44 port.
#
# See docs/kdos/03-architecture/session.md.
#
# This list names every port the phase installs and nothing it does not;
# testing/phaseclosure.py fails when a dependency pulls a port in from outside
# it, or when a shelf section names a port an earlier phase installs.

# ---------------------------------
# src-daemons — KDOS's own root daemons, from src/daemons
# ---------------------------------

# The firewall's named services, the accent and the boot splash, for a desktop
# that is not root: a unix socket in /run gated by SO_PEERCRED, and
# io.kdos.Power1 on the system bus, which asks polkit for anyone not in wheel.
kdos-powerd

# Per-app Energy Impact. RAPL is root-only (PLATYPUS), so the sampler is a
# daemon; identity comes free from the fact that every alien app is already its
# own container. Relative shares, never watt-hours.
kdos-energyd

# Wedge protection under memory pressure. Blocks on a /proc/pressure/memory PSI
# trigger and SIGKILLs + process_mrelease()s the largest attributable offender —
# preferring boxed apps, never the Plasma session itself — at most once per ten
# seconds. Same shape as kdos-powerd: root, foreground under ksvc, SO_PEERCRED
# socket for `kdos doctor`.
kdos-oomd

# Packs. An application is one signed EROFS image with a KDOS footer on the
# end, and this is the only thing on the machine that mounts one: it verifies
# where it mounts, composes a box's root filesystem out of an overlay of them,
# and takes an id out of the list it published rather than a path. Mounting as
# ROOT is what makes overlay whiteouts real: a box's root is composed from the
# packs as they are, with no flatten step.
kdos-packd

# hostname1, timedate1 and locale1 on the system bus, written to the files
# KDOS keeps, for System Settings, the greeter and plasma-setup.
kdos-settingsd

# org.freedesktop.sysupdate1 and io.kdos.Slots1 over the A/B root slots: what
# Discover's system updates and the slots page ask.
kdos-sysupdated
