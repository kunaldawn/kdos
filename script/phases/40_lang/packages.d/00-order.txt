#
# Language modules and developer tools — the python3-* and perl-* modules,
# language implementations, build and documentation tools, debuggers and
# version control — whose dependency closure needs nothing past 31_compilers.
#
# The files in packages.d are read in sorted order as one list. Together they
# name every port the phase installs and nothing it does not;
# testing/phaseclosure.py fails when a dependency pulls a port in from outside
# them, or when a shelf file names a port an earlier phase installs.
#
# This file sorts first, so its runs install before any shelf file's ports, in
# the order written. A run is here because a comment pins its order; everything
# else is in the file of its shelf.
#
# Under `kdosbuild --port-jobs` this file is also the phase's serial prefix:
# its ports, and every port the resolved order puts among them, build and
# install one at a time, and no other port of the phase starts before the last
# of them is installed. A pair whose order matters only because both install
# the same path is pinned here too; kdosbuild names such a pair when a level's
# commit moves a path the serial order would not have.
#
# It is also the one file that may name a port an earlier phase installs: kpkg
# skips that port while its recipe hash is current and rebuilds it here, in this
# order, when the recipe has changed.

toybox

# A toybox upgrade removes the names its previous manifest held, and a toybox
# installed after a port holds that port's names — cmp, readelf, strings,
# gunzip, mount, insmod. So a name toybox compiles out needs a recipe change (a
# release bump) to the port that owns it in the same change: kpkg skips a port
# whose recipe hash is current wherever it is listed, and without the bump the
# name stays missing. These are the owners 20_selfhost and 30_foundation
# install before toybox, plus sed and findutils, which take back the sed, find
# and xargs a toybox upgrade puts back; ncurses, e2fsprogs and procps-ng are
# bumped the same way, and e2fsprogs and procps-ng reinstall in 41_system.
#
# Their place straight after toybox, at the head of the first phase after
# 31_compilers, only brings the names back before anything later needs them —
# bzip2's `make` runs `cmp` — and a port listed only in 30_foundation never
# reinstalls in a run that continues from 40_lang.
