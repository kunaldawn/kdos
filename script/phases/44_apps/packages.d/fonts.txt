# The same face as terminus-font, scalable. pango does not render bitmap fonts
# since 1.44, so labwc's titlebars, root menu and window-switcher OSD cannot
# use terminus-font's PCF and silently draw in DejaVu Sans without this. Its
# family is `Terminus (TTF)`, deliberately distinct upstream, so fcft keeps
# drawing the crisp bitmap for the cell grid and only the pango surfaces ask
# for this one.
terminus-ttf

# The colour emoji face, which the rest of the font configuration already
# assumes: `70-no-bitmaps-except-emoji` carves bitmap fonts an exception BY
# FAMILY, and with no such family every emoji on the image is a blank box.
noto-emoji
