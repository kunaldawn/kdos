# Watching a topic tree is how an MQTT problem is diagnosed; mosquitto_sub
# prints a stream and this shows the tree it belongs to.

# Which hop is losing packets and by how much, continuously — the question on
# a link that works except when it does not. Needs CAP_NET_RAW, granted
# deliberately rather than shipped setuid.
trippy

# Needs CAP_NET_RAW and is not given it — there is no third setuid program on
# this system and a packet sniffer is not the one to add.
bandwhich
