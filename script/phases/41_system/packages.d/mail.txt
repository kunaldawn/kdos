# THE TOKEN A PROVIDER WANTS INSTEAD OF A PASSWORD. aerc and msmtp can both
# present one; mbsync cannot, and no minter changes that — see
# ports/core/mail/isync/build.sh. Rust, and its HTTP client is rustls, so
# nothing links openssl for it.

# THE WRITER notmuch indexes after. mbsync makes an IMAP mailbox and ~/Mail
# equal in both directions and indexes nothing, which is why `notmuch new` runs
# it from a pre-new hook and then indexes what it left: one command fetches and
# files, and nothing has to remember the order. XOAUTH2 is reached through
# cyrus-sasl and cyrus-sasl-xoauth2; OAUTHBEARER is not, and is aerc's.
isync
