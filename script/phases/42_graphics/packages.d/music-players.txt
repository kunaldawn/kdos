# Ports whose dependency closure reaches wayland, libX11, mesa, libdrm, cairo,
# pango, gstreamer, ffmpeg or pipewire but no toolkit, and that are not leaf
# applications.

# The files in packages.d are read in sorted order as one list. Together they
# name every port the phase installs and nothing it does not;
# testing/phaseclosure.py fails when a dependency pulls a port in from outside
# them, or when a shelf file names a port an earlier phase installs.

# The player and the playback are separate processes: the music survives the
# terminal closing, the session locking and the client dying, and a client can
# attach from anywhere that reaches the socket — including over ssh from
# another machine on the LAN. mpd is the daemon half and ships no
# configuration, so it has a library only once somebody writes one — and the
# session starts it, and the panel's now-playing watcher, only then.
