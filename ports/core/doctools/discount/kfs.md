## About
[Discount]{.idx} is a Markdown implementation in C: `libmarkdown`, a library that turns Markdown
into HTML, and the `markdown` command built on it. [okular](#port-okular)'s Markdown generator
and [labplot](#port-labplot) link the library.

## Flags
- `--shared` — Build `libmarkdown` as a shared library. The script's default is a static one.
- `--pkg-config` — Install `libmarkdown.pc`, through which the library's consumers find it.
- `--container` — Do not run `ldconfig` on the installed library. The install script it writes
  otherwise runs it against the library directory.

## Patches
- `install-data-mode.patch` — Changes the mode of `INSTALL_DATA` in `configure.inc` from `444` to `644`. The header `mkdio.h`, `libmarkdown.pc` and the manual pages are installed with it, so they are installed writable by their owner (`rw-r--r--`) instead of read-only for everyone (`r--r--r--`).

## Notes
`configure.sh` is Discount's own configuration script, not one generated by autoconf. It takes
`--prefix`, `--libdir` and `--mandir` as autoconf's do, and switches of its own for the rest,
which `./configure.sh --help` lists.
