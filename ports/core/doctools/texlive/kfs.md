## About
[TeX Live]{.idx} is the TeX distribution: TeX, pdfTeX, XeTeX and LuaTeX, LaTeX, MetaPost, BibTeX,
dvips, dvisvgm and the rest of the tools, with the macro packages and
fonts they read. The port compiles every engine and program from the source tarball and ships a
cut of upstream's texmf tree, the runfiles of a fixed set of collections and the packages they
depend on, with its formats, font maps and file databases generated by the binaries just built.
[LyX](#port-lyx) and [TeXstudio](#port-texstudio) name it in `depends`;
[texlive-doc](#port-texlive-doc) ships the English documentation of the same cut.

## Flags
- `--disable-native-texlive-build`, `--disable-multiplatform` — Build for a distribution rather
  than for TeX Live's own binary release, with programs in `bindir` and libraries in `libdir`
  instead of in `bin/<platform>` and `lib/<platform>`.
- `--disable-missing` — Stop the configure when a requested program or feature would be
  disabled for a missing library, instead of building without it.
- `--enable-shared` — Build TeX Live's libraries, `libkpathsea` and `libsynctex` among them, as
  shared libraries.
- `--with-banner-add=/KDOS` — Append `/KDOS` to the version string in every engine's banner, so
  a log says whose build of TeX Live wrote it.
- `--without-x`, `--disable-xdvik` — Build no X programs: no `xdvi`, which needs the Xaw widget
  library (not a port), and no X window for METAFONT. `--without-x` also turns off `xpdfopen`;
  `--disable-xpdfopen` says so explicitly. A TeX preview on this desktop is a PDF viewer.
- `--disable-xindy` — Do not build xindy, the index processor, which needs CLISP. CLISP is not a
  port.
- `--with-system-zlib`, `--with-system-libpng`, `--with-system-freetype2`, `--with-system-gmp`,
  `--with-system-mpfr`, `--with-system-cairo`, `--with-system-pixman`, `--with-system-gd`,
  `--with-system-potrace`, `--with-system-libpaper`, `--with-system-icu`,
  `--with-system-harfbuzz`, `--with-system-graphite2`, `--with-system-zziplib` — Link these
  libraries from the tree instead of TeX Live's copies under `libs/`. Every one is a port in
  `depends`. TeX Live's own copies are built of TECkit and MPFI, which are not ports, of
  LuaJIT and Lua, and of pplib (LuaTeX's PDF reader) and xpdf's code (pdfTeX's).

## Patches
- `texmfmp-fix-format-specifier.patch` — Changes the conversion for `inopen` and for `inputstack[].namefield` from `%d` to `%ld` in the error messages `calledit()` in `texk/web2c/lib/texmfmp.c` prints when the editor-call state is inconsistent.
- `dvisvgm-cxx20.patch` — Makes dvisvgm compile as C++20, GCC's default standard, since dvisvgm passes no `-std`: `MemoryFontData` loses its deleted default constructor so its font data can be brace-initialised, the ligature table's `u8` literals become plain literals (under C++20 they are `char8_t`, not `char`), and Clipper's `pt.Z != 0` compares against `ZType(0)` to remove an ambiguous comparison. It also adds a `toLigature` unit test. See [u8 literals under C++20](../../../../docs/kdos/05-developer/build-troubleshooting.md#u8-literals-under-c20).
- `texmfcnf.patch` — Applied to the installed tree, not the source: sets `TEXMFROOT` in `texmf-dist/web2c/texmf.cnf` to `/usr/share` instead of `$SELFAUTOPARENT`, a path computed from where the binary sits, and `TEXMFLOCAL` to `$TEXMFROOT/texmf-local`, so kpathsea finds the trees at `/usr/share/texmf-dist`, `/usr/share/texmf-var` and `/usr/share/texmf-local`.

## Notes
- **Four sources.** The source tarball builds the programs. The texmf tarball is the whole of
  upstream's `texmf-dist`. The installer tarball supplies `tlpkg/TeXLive`, the Perl modules that
  read the package database and that `updmap` and `fmtutil` load from `$TEXMFROOT/tlpkg`. The
  tlpdb bundle is `texlive.tlpdb` at the release's svn tag, the database the texmf tarball was cut
  from, made by hand; how to rebuild it is in
  [A bundle no tool writes](../../../../docs/kdos/05-developer/writing-ports.md#a-bundle-no-tool-writes).
- **The cut.** The Perl block after `make install` reads the tlpdb, takes the closure of
  `TL_ROOTS` over each package's dependencies, and moves each selected package's runfiles from the
  texmf tarball into the package, over any copy `make install` wrote. A runfile the tarball lacks
  stops the build. The selected packages' manual pages and info files go to `/usr/share/man`
  and `/usr/share/info`, never over a page `make install` already put there. It then writes
  `fmtutil.cnf`, `updmap.cfg`, `language.dat`, `language.def` and `language.dat.lua` from the
  selected packages alone, because a format, a font map or a hyphenation file named for a package
  that is not shipped makes `fmtutil` and `updmap` fail. The selected packages' records become
  `/usr/share/tlpkg/texlive.tlpdb`, which `texdoc` reads to map a package to its documentation
  and refuses to run without. [texlive-doc](#port-texlive-doc) cuts the same closure, so the two
  recipes must name the same `TL_ROOTS`.
- **No tlmgr.** The package manager is kpkg; `tlmgr` installs from the network into a tree kpkg
  owns. `build.sh` removes the `tlmgr` command, its manual page, and `tlmgr.pl` and
  `tlmgrgui.pl` from the texmf tree. What `make install` puts under `texmf-dist/doc` is
  removed too; texlive-doc ships the documentation from the tlpdb's own file lists.
- **No prebuilt Java.** The texmf tree carries upstream-built `.jar` files (arara, bib2gls,
  texosquery, pax and others), and nothing here compiles them. `build.sh` deletes every `.jar`,
  and every command in `/usr/bin` that is a link into a directory holding one, since kept, such a
  command would run a binary nobody here built; see
  [What is built from source](../../../../docs/kdos/05-developer/writing-ports.md#what-is-built-from-source).
  The Type 1, OpenType and TFM font files of the tree are shipped as upstream made them, under
  the same page's exemption for compiled font data.
- **Formats are generated at build time.** With `PATH`, `LD_LIBRARY_PATH`, `TEXMFROOT` and
  `TEXMFCNF` pointing at the package, `build.sh` runs `texlinks`, `mktexlsr`, `updmap-sys` and
  `fmtutil-sys --all` with the binaries just built, removes the logs, and rebuilds the file
  databases (`ls-R`) last. `FORCE_SOURCE_DATE=1` makes every engine stamp its formats with
  `SOURCE_DATE_EPOCH` instead of the time of the build. Finally `find -xtype l -delete` removes
  the commands `texlinks` and `make install` linked to scripts of packages outside the cut.
- **TeX fonts are available to fontconfig, not enabled.** XeTeX finds a font by name only through
  fontconfig. `09-texlive-fonts.conf` names the tree's `opentype` and `truetype` directories and
  is installed in `conf.avail`, not linked into `conf.d`: enabled, it would put every math and
  text face of the tree in every application's font list. A document that names its fonts by file,
  as Latin Modern and LaTeX's TU font definitions do, needs neither.
- **latexindent's modules.** `latexindent` loads `YAML::Tiny` and `File::HomeDir` when it
  starts and dies without them; [perl-yaml-tiny](#port-perl-yaml-tiny) and
  [perl-file-homedir](#port-perl-file-homedir) are in `depends` for it.
