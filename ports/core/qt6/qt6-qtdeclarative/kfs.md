## About
Qt Declarative is QML and Qt Quick for Qt 6: the QML language and its JavaScript engine, the Qt
Quick scene graph, Qt Quick Controls and Layouts, and the tools around them (`qml`, `qmllint`,
`qmlformat`, `qmlls`, `qmlcachegen`). KDE's applications and every Qt program whose interface
is written in QML need it at run time.

## Flags
- `-DFEATURE_qml_python=ON` — require a Python interpreter for the build. The YARR regular
  expression engine inside the QML engine has its JIT tables, `RegExpJitTables.h`, generated by
  a Python script, which is why [python3](#port-python3) is in `depends`.
- `-DFEATURE_qml_jit=ON` — the just-in-time compiler for QML and JavaScript, which upstream
  offers on x86-64 and the other architectures it lists. Upstream's default there, named.
- `-DFEATURE_qml_network=ON` — with `-DFEATURE_qml_ssl=ON`: let QML load components and images
  from a URL, and over TLS. Upstream's defaults where QtNetwork and SSL exist, named.
- `-DFEATURE_quick_vectorimage=ON` — the `VectorImage` item, which draws an SVG as Qt Quick
  shapes. It needs Qt SVG, which is why [qt6-qtsvg](#port-qt6-qtsvg) is in `depends`.

## Notes
Like every Qt 6 module but `qt6-qtbase`, it passes no install paths of its own (see [How Qt 6 is built](../../../../docs/kdos/05-developer/writing-ports.md#how-qt-6-is-built)).
