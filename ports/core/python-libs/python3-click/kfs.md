## About
[Click]{.idx} builds command-line interfaces for Python programs from decorated functions:
options, arguments, nested commands, help text and shell completion. It is pure Python, built
with flit_core, and imported by [khal](#port-khal), [vdirsyncer](#port-vdirsyncer),
[toot](#port-toot), [python3-esptool](#port-python3-esptool), [gnuradio](#port-gnuradio) and the
other ports that name it.
