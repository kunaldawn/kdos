## About
[psutil]{.idx} reports processes, CPU, memory, disks, network and sensors from Python, reading
`/proc` and `/sys` and, for some figures, the kernel's ioctl interfaces through a C extension
(`psutil/_psutil_linux.abi3.so`). [ipython](#port-ipython), [spyder](#port-spyder),
[jupyterlab](#port-jupyterlab) and [calibre](#port-calibre) are among the ports that import it.
