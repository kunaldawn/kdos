## About
[six]{.idx} is a single module of compatibility helpers for code written to run on both Python 2
and Python 3. Code that still imports it needs it at run time:
[python3-dateutil](#port-python3-dateutil), [python3-html5lib](#port-python3-html5lib),
[calibre](#port-calibre), [khal](#port-khal) and the other ports that name it in `depends`.
