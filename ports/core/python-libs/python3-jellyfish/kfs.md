## About
[jellyfish]{.idx} does approximate and phonetic string matching in Python: string distances
and similarities (Levenshtein, Damerau-Levenshtein, Hamming, Jaro, Jaro-Winkler, Jaccard) and phonetic codes (Soundex,
Metaphone, NYSIIS, Match Rating). Its implementation is Rust, built by
[maturin](#port-python3-maturin) from the vendor bundle into `jellyfish/_rustyfish`.
[spyder](#port-spyder) depends on it.
