## About
[rpds-py]{.idx} binds the Rust `rpds` crate's persistent (immutable, structurally shared) data
structures to Python as `HashTrieMap`, `HashTrieSet`, `List` and `Queue`. It is built by
[maturin](#port-python3-maturin) from its vendor bundle.
[python3-referencing](#port-python3-referencing), the reference resolver under
[python3-jsonschema](#port-python3-jsonschema), imports it.
