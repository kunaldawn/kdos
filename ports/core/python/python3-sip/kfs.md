## About
[SIP]{.idx} generates Python bindings for C and C++ libraries from `.sip` specification files,
and is the build system those bindings are built with (`sip-build`, `sip-install`, `sip-wheel`).
PyQt is written in it: [python3-pyqt5](#port-python3-pyqt5), [python3-pyqt6](#port-python3-pyqt6),
[python3-qscintilla](#port-python3-qscintilla) and [qgis](#port-qgis) are among the ports that
name it in `depends`, and [python3-pyqt-builder](#port-python3-pyqt-builder) extends it for Qt
projects.
