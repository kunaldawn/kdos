## About
[pybind11]{.idx} is a header-only C++ library for exposing C++ code to Python, with the CMake
and setuptools glue to build such a module. [matplotlib](#port-matplotlib),
[scipy](#port-scipy), [freecad](#port-freecad), [gnuradio](#port-gnuradio) and the other ports
that name it compile their bindings against its headers. It builds with scikit-build-core,
which is the [python3-scikit-build-core](#port-python3-scikit-build-core) port.
