## About

Every file of [linux-firmware](#port-linux-firmware) no vendor port's rule takes: the Cirrus Logic
and TI sound amplifiers of many laptops, Marvell, Mellanox, Netronome, QLogic, Chelsio and NXP
networking, TV tuners and capture cards, USB serial adapters and the older Wi-Fi chips. 3,427 files
and links, 121,511,339 bytes. It is not on the installation medium; `kdos firmware sync` installs
it.

## Flags

- `--zstd` — Compresses every `File:` entry of `WHENCE` as `copy-firmware.sh` copies it; see
  [linux-firmware](#port-linux-firmware), whose note describes the build every port of the set
  shares.
