## About

SWIG reads C and C++ headers, with an interface file saying what to expose, and writes the glue
code that lets a scripting language call that library. In KDOS it is a build tool only: the ports
that ship Python or other language bindings generated by SWIG name it in `depends`, among them
`gdal`, `lldb`, `kicad`, `freecad` and its `pivy` and `ifcopenshell`, `gnucash`, `obs-studio`,
`kodi` and `libcec`.

## Flags

- `--without-maximum-compile-warnings` — SWIG's `configure` adds `-Wall -W -pedantic` to the
  flags it compiles SWIG itself with unless this is given. It changes only the warnings printed
  while SWIG is compiled, not the code built.
- `--with-pcre` — build SWIG with PCRE2. This is upstream's default too, and with it `configure`
  stops if it cannot find `pcre2-config`, rather than building a smaller SWIG. PCRE2 is what the
  `regex:` form of `%rename` uses to apply a Perl-style substitution to identifiers; a SWIG built
  without it stops on any interface file that uses that form, with "PCRE regex support not enabled
  in this SWIG build".
