## About

{fmt} is a C++ text-formatting library and an implementation of C++20's `std::format`:
type-safe `fmt::format("{}", x)` and `fmt::print` with Python-style replacement fields, plus
formatters for chrono types, ranges, colours and the rest of the standard library. Many ports link
it, among them [spdlog](#port-spdlog), which this tree builds against it with
`SPDLOG_FMT_EXTERNAL=ON` rather than with the copy spdlog carries, [mpd](#port-mpd),
[mkvtoolnix](#port-mkvtoolnix) and [blender](#port-blender). They find it through `fmt-config.cmake`
or `fmt.pc`, both of which this package installs.

## Flags

- `-DBUILD_SHARED_LIBS=ON` — `add_library(fmt …)` names no library type, so CMake's default decides
  it, and that default is static. With the switch on, the package installs `libfmt.so` and its
  versioned links, and its CMake targets carry `FMT_SHARED` to every consumer, so a program links
  the one shared copy instead of compiling the formatter in. The small C wrapper `libfmt-c.a` is
  declared `STATIC` by upstream and stays a static archive either way.
- `-DFMT_TEST=OFF` — The test suite is built by default when fmt is the top-level project. It is not
  run by the port, so this saves compiling it.
- `-DFMT_DOC=OFF` — The `doc` target is generated by default as well. It needs both doxygen and
  mkdocs, and the tree has no mkdocs port, so CMake would only print that the target is disabled.
