# ---------------------------------
#   The palettes of the add-on set, one block each.
#
# genaddons.py turns each block into a Konsole colour scheme and a KDE colour
# scheme of the same name. The values are each palette's published ones;
# genaddons.py never ships a text colour that fails WCAG AA (4.5:1) on the
# background it is drawn on, and moves one toward the scheme's own text
# until it passes, so a palette here may hold a colour too faint to read.
#
#   id          the file name of both schemes; never KDOS-prefixed, which is
#               the accents' namespace that `kdos theme` rewrites
#   ansi        Color0..Color7, then their intense forms
#   background  the terminal's ground, foreground its text
#   window ...  the KDE roles: window, view, alternate, button, header,
#               selection and its text, link, visited, negative, neutral,
#               positive; a role left out is derived
#   licence     an SPDX id, with copyright and source: the pack's kfs.md
#               lists them
# ---------------------------------
