title: a launcher's FILENAME must be upstream's own desktop id
cite: kdos-appbox genlaunchers
port: kdos-appbox

Plasma's Task Manager matches a running window to a desktop entry by the
entry's FILE ID, not by StartupWMClass — so `kdos-<name>.desktop` beside a
pinned icon shows a second, generic icon. Kickoff, KRunner and the Task
Manager all agree on upstream's id, which is why it is the right filename.

And a Wayland app_id is NOT the X11 WM_CLASS: GIMP's entry says
StartupWMClass=gimp-3.0 while its toplevel calls set_app_id("gimp") — measured
with WAYLAND_DEBUG=1, not guessed.
