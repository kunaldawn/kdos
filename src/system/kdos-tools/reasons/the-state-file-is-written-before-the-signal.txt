title: write the accent state file BEFORE the switch, not after
cite: kdos theme
port: kdos-tools

`kdos theme` writes ~/.config/kdos/accent first, atomically, and only then
applies the global theme. The KDOS kded module compares the Global Theme page
against exactly that file: apply first and a reader in between sees the new
theme beside the old accent, takes it for a foreign scheme, and undoes the
switch the person asked for.

Everything else `kdos theme` writes — qt5ct, Konsole, the terminal programs —
exists for software that cannot read the accent from Plasma and cannot be
told.
