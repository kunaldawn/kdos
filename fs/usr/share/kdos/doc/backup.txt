KDOS BACKUP

What is in the restic repository, newest first, one key to add to it, and
the way back out of it.

  Enter     opens the selected snapshot in the restore view.
  b         backs up now. It does not wait: a first run over a home directory
            is minutes to hours, and the snapshot appears in the list when it
            finishes.
  r         re-reads the repository.

Restoring

  The restore view lists one folder of the snapshot at a time.

  Enter     opens the selected folder.
  Backspace goes up one folder.
  t         restores the selected file or folder.
  Esc       goes back to the list of snapshots.

  A restore lands in ~/Restored/<snapshot>/, with the entry's whole path
  recreated beneath it: /home/kdos/Documents/notes.txt from snapshot e399cdcf
  comes back as ~/Restored/e399cdcf/home/kdos/Documents/notes.txt. It never
  writes over the original, so you compare the two and move what you want.
  restic's last line shows while it runs, and closing the window does not
  stop it.

  `restic restore` at a terminal does everything this does and more — a
  restore to another place, a whole snapshot, a pattern. `restic help restore`
  lists the options.

Configuration

  ~/.config/kdos/backup.conf, one `key = value` per line:

    repo    = /var/backup/kdos       where the repository is
    include = /home/kdos             what goes in it; may repeat
    exclude = /home/kdos/.cache      what does not; may repeat

  The repository is made once with `restic -r <repo> init`, which asks for the
  password twice and writes nothing down.

The password

  ~/.config/kdos/backup.pass, mode 0600, holding the repository password and
  nothing else. `password-file =` in backup.conf points somewhere else if you
  keep it somewhere else.

  This window refuses to run when that file is group or world readable, before
  it uses it. A password file at 0644 hands the key to every backup on this
  machine to every account on it, and 0644 is what a text editor leaves.

  It is a file and not a keyring because there is no keyring here: nothing on
  this system provides the Secret Service, and `pass` wants a GnuPG key the
  installer does not make.

Running it every night

  /etc/kdos/timers.d/ and ~/.config/kdos/timers.d/ hold one line per job:

    backup 03:17 -- kdos-backup --once

  See [[doc:index]] for the timer format.
